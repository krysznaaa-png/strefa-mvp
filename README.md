# STREFA MVP

Pierwszy prototyp aplikacji STREFA oparty na przekazanej analizie architektonicznej.

## Uruchomienie
npm install
npm run dev

## Zakres demonstracyjny
Dashboard, odkrywanie usług, rezerwacje, Wallet, benefity/Loyalty i profil.
Dane są demonstracyjne — nie ma jeszcze prawdziwych płatności, autoryzacji ani backendu.

## Wdrożenie
Projekt jest przygotowany jako aplikacja Next.js do wdrożenia na Vercel.
